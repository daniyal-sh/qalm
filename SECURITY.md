# Security

## Reporting a vulnerability

Please email **[privacy@apollolearn.app](mailto:privacy@apollolearn.app)**. Don't open a public issue or pull request
for a vulnerability.

Include what you found, where (the app, the desktop app, the API at `qalm-api.apollolearn.app`, MCP, the website),
steps to reproduce, and the impact you expect. A proof of concept helps.

## What to expect

- We acknowledge your report within **3 working days**.
- We give you a first assessment within **10 working days**, and keep you posted until it's fixed.
- We credit you when the fix ships, if you'd like.

Please give us reasonable time to fix the issue before you disclose it, and don't access other people's data, degrade
the service or use social engineering while testing. Test against your own account, or better, your own server
([self-hosting](README.md#self-host-the-server-on-cloudflare)).

## Scope

The code in this repository and the service at `qalm.apollolearn.app` and `qalm-api.apollolearn.app`. qalm is in
beta; only the latest `main` is supported.
